This package was built from your actual GitHub repository.

UPLOAD TO GITHUB
1. Keep a backup of the current repository.
2. Open this ZIP and then the folder PoC_Radio_Lab_Europe_Portal_v2_Stage_3.
3. Select all files and folders inside it.
4. On GitHub choose Add file > Upload files.
5. Drag all selected files and folders onto the upload area.
6. Existing files such as index.html and main.css will be replaced; new folders will be added.
7. At the bottom click Commit changes.
8. Wait approximately 1–3 minutes for GitHub Pages deployment.

The CNAME file is preserved, so pocradiolab.eu remains connected.
